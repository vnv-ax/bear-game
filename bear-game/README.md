# Мишка-грустишка

Спокойная 3D-игра-наблюдение: медведь живёт своей жизнью в лесу рядом с водоёмом, а игрок наблюдает и изредка вмешивается тапами курсора или пальца.

Игра собрана на **Next.js + three.js + cannon-es** и полностью работает на клиенте — её можно разместить на GitHub Pages.

## Управление

| Действие | Результат |
| --- | --- |
| Перетащить мышью пустое место | Вращение камеры вокруг медведя |
| Колесо мыши / щипок | Приблизить и отдалить |
| Клик по медведю или рядом | Иногда реагирует: отмахнётся лапой, подойдёт, уйдёт, сядет или сделает вид, что не заметил |
| Клик по камню / ветке / яблоку | Взять предмет |
| Перетащить и отпустить | Бросок по направлению взмаха |
| Клик при удержании предмета | Бросок в точку под курсором (и в медведя — тоже) |
| Яблоко или ягода рядом с медведем | Мишка замечает и съедает |
| Нажать на медведя и тянуть | Вырывается и смотрит на руку |
| Потянуть медведя вверх / резко толкнуть | Подброс: кувырок в воздухе, приземление на лапы, дальше — обида, злость или бегство |
| Клик по воде | Всплеск и круги, рыба пугается и разбегается |
| Крошечная кнопка «✦» внизу справа | Волшебный красочный режим с лёгким сюрреализмом |

## Что делает медведь

Гуляет по лесу, спит (~3 минуты, разбудить непросто — понадобится три тычка), ест ягоды с кустов и яблоки под яблонями (подойдёт и к брошенному рядом яблоку), пьёт и ловит рыбу, чешет спину о деревья, точит когти, гоняется за бабочками, иногда роет ямки с холмиком земли, а иногда внезапно бесится и носится туда-сюда или бегает за мышью.

Если его слишком часто дёргать — демонстративно садится задом к камере. Если ещё больше бесить — носится и дерётся с невидимыми противниками. О задуманном рассказывает облачком мыслей над головой.

Дождь идёт редко; после него в небе может выплыть радуга. В дождь медведь прячется под крону дерева.

Мыши, бабочки и птички живут своей жизнью. Птицы — классическая «птица из three.js» (геометрия и взмах крыльев из примеров three.js, MIT).

## Технологии

- **three.js** — рендер, тени, инстансинг деревьев и травы, GLB-модели
- **cannon-es** — физика камней, веток, валунов и брёвен, heightfield рельефа, засыпание предметов, плавучесть
- **Next.js** (App Router, статический экспорт) — сборка и размещение

Деревья и трава — из GLB-сцены (23 варианта коры и листвы, инстансинг `InstancedMesh`). Медведь — GLB-модель с 81 анимацией (locomotion, сон, еда, злость, переходы сидя/лёжа).


## Размещение на GitHub Pages

### Вариант 1 — GitHub Actions (рекомендуется)

1. Загрузите этот репозиторий на GitHub (ветка `main`).
2. В настройках репозитория: **Settings → Pages → Source → GitHub Actions**.
3. Workflow `.github/workflows/deploy-pages.yml` соберёт статический экспорт и задеплоит его автоматически при каждом пуше.

Игра будет доступна по адресу `https://<ваш-логин>.github.io/bear-game/`.

Если переименуете репозиторий — поменяйте `NEXT_PUBLIC_BASE_PATH` в workflow на `/имя-репозитория`.

### Вариант 2 — собрать и выложить вручную

```bash
# Linux / macOS
npm run build:pages          # = NEXT_PUBLIC_BASE_PATH=/bear-game PAGES_EXPORT=1 next build

# Windows (PowerShell)
$env:NEXT_PUBLIC_BASE_PATH="/bear-game"; $env:PAGES_EXPORT="1"; npx next build
```

Содержимое папки `out/` выложите в ветку `gh-pages` (или в папку `docs` на `main`), затем включите Pages в настройках.

> В готовой папке хостинга (статический экспорт) базовый путь уже проставлен для репозитория `bear-game`.

## Структура проекта

```
src/
  app/            страница Next.js (маршрут «/»), стили HUD
  components/     BearGame.tsx — React-обёртка: загрузка, HUD, кнопка «✦»
  game/
    config.ts     константы мира, аналитическая высота рельефа
    terrain.ts    визуальный рельеф + cannon-es Heightfield
    water.ts      шейдерная вода, круги, всплески
    sky.ts        небо, солнце, облака, дождь, радуга
    trees.ts      деревья/трава из GLB (инстансинг), кусты, яблони
    props.ts      камни, ветки, валуны, брёвна, яблоки (cannon-es)
    bear.ts       медведь: 81 анимация, движение, «мозг»
    thought.ts    облачко мыслей
    creatures.ts  рыбы, мыши, бабочки (GLB)
    birds.ts      птицы из three.js
    magic.ts      волшебный режим «✦»
    Game.ts       сборка сцены, камера-орбита, ввод, частицы
public/models/    bear.glb, butterfly.glb, tree_scene.glb
```

## Модели и лицензии

Код — MIT. Модели с Sketchfab, все под **CC-BY-4.0**:

- Медведь — [Realistic Animated Bear 3D Model](https://sketchfab.com/3d-models/realistic-animated-bear-3d-model-bffc3c87d2d148ff8533e1cc8a11c9f1) от WildMesh 3D
- Бабочка — [BUTTERFLY](https://sketchfab.com/3d-models/butterfly-d642db74a3fa491a8143bd088b408094) от Rukh3D
- Деревья и трава — [Low Poly Tree Scene Free](https://sketchfab.com/3d-models/low-poly-tree-scene-free-89daa5e21f0d4f08a59dba0d566e88bd) от Nicholas-3D

Птица — адаптация классической птицы из примеров three.js (MIT). В модели `bear.glb` материалы заранее конвертированы из `KHR_materials_pbrSpecularGlossiness` в стандартный `pbrMetallicRoughness` (совместимость с современным GLTFLoader).

> Примечание: файл `a_forest_3_with_a_road_at_night_for_game.glb` (ночной лес с дорогой) в игре не используется — сцена строится из low-poly набора деревьев; птица по задумке взята из three.js, поэтому `hummingbird__rigged_6_animations_open_bill.glb` тоже не подключён.
